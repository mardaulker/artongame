# Asset sources and licenses

## Character and animations

Microsoft Rocketbox Female_Adult_07 and compatible idle/walk/run animation clips.

Source: https://github.com/microsoft/Microsoft-Rocketbox

MIT License. Copyright (c) 2020 Microsoft. The full required notice is retained in `character/LICENSE-Microsoft-Rocketbox.md`.

Textures were encoded as WebP, retaining original 2048×2048 dimensions. Animation JSON was exported with Three.js, with clip names assigned, missing helper tracks removed and horizontal root translation cleared for controller-based movement.

## Stone textures

- Stone Tile Wall, Charlotte Baglioni: https://polyhaven.com/a/stone_tile_wall
- Rustic Stone Wall 02, Amal Kumar: https://polyhaven.com/a/rustic_stone_wall_02
- Medieval Blocks 03, Rob Tuytel: https://polyhaven.com/a/medieval_blocks_03

CC0. License: https://polyhaven.com/license

The original 1K/2K JPG maps are included at their downloaded dimensions: diffuse, OpenGL normal, roughness and ambient occlusion.

Character textures are distributed as WebP; stone maps remain JPG. All runtime assets are served locally by this application.
